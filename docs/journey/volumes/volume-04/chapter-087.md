## Chapter 87 — The importmap self-install bet pays off, and the agents diverge on *how* to implement the same convention (2026-06-14)

The headline experiment of iteration-0005 was whether a frontend agent, handed only the *intent* ("hover-capable JS charts, install what you need via importmap"), would figure out the library install itself. The Amortization regen agent did exactly that: it detected the chart libraries weren't pinned and **installed them itself**, vendoring them under `vendor/javascript` (no runtime CDN) — **lightweight-charts** @5.2.0 (+ its `fancy-canvas` dependency) for the balance-over-time area chart with crosshair/tooltip, and **Chart.js** doughnut for principal-vs-interest with hover tooltips. It even navigated a real packaging snag on its own: the jspm/jsDelivr dist builds of chart.js *"split into sub-chunks … that `bin/importmap` does **not** download, so they 404 at runtime,"* and it resolved it by switching to the self-contained `chart.js/auto` esm.sh bundle. The assistant recorded the result plainly: *"the importmap self-install bet **paid off**: the agent detected the chart libs weren't pinned and installed them itself … It even hit and solved a real snag on its own."*

But the evaluate phase began surfacing signal *during* the build. The assistant noticed the agents had **diverged on how to implement the same convention**: BMI introduced a shared `.stat-grid`/`.stat-card` component in `application.css`, while Ohms/Tip/others inlined the `auto-fit` classes at varying min-widths (8/9/9.5/11/13rem). It flagged this in real time as harvest material: *"That's exactly the kind of inconsistency the evaluate→harvest loop should catch (likely → codify 'stat grid = a shared BLEND component' in DESIGN.md next harvest)."* This is a subtle but real datum about the from-spec sweep: handed the same convention, eight independent agents produced eight *correct* but *inconsistent* implementations — the convergence loop reached the *what* (every grid is responsive and never clips) but not the *form* (one shared component vs. inlined utilities). The agents also self-caught some of their own clipping: the Simple Interest agent's *"first attempt at 9rem min clipped the total at scale; I caught it in the pixel review and fixed it to 11rem before committing."* **Agent/doc-driven? ✅** — the self-install bet is a strong positive autonomy datum, and the implementation divergence is a precise instance of the evaluate→harvest loop producing its own next-round agenda mid-iteration.
