## Chapter 88 — The visual gate catches two real chart bugs nothing else did — its strongest validation yet (2026-06-14)

When the operator asked whether to merge regens on CI-green alone — *"Should we start merging all of the ones that have CI green btw?"* — the assistant held a qualifier: these are **UI-surface** PRs, so they merge only on CI-green *and* a visual approval. That qualifier immediately earned its keep. The Amortization visual review **caught two genuine chart defects that every markup test and the agent's own local Mac screenshot had passed**: the principal-vs-interest **donut rendered blank** (Chart.js had been handed the wrapper `div`, not the `<canvas>`), and the balance curve's **x-axis showed "1970"** (a month index read as a UNIX timestamp). The assistant named it as the gate's strongest validation: *"the **Amortization review caught two *real* chart bugs** that every markup test + the agent's local Mac screenshot missed … Strong validation that the visual gate earns its keep — and exactly why I won't merge these UI regens on CI-green alone."*

The fix went back to the agent, which repaired both and — critically — added a **pixel-level "chart actually painted" test**: the donut must have more than 500 painted pixels, *"so a blank chart now fails CI."* This closes the structural hole the build exposed: a JS-painted `<canvas>` cannot be asserted by the markup-only integration suite, so a chart that silently fails to draw passes every test; the pixel-test makes "did it paint?" a mechanical CI gate rather than a human-eyeball check. The re-review confirmed both charts now paint correctly — donut with the largest slice green per §1, balance curve declining from ~$100k to $0 with a proper "Start … Yr 25" axis — and called it *"a clear upgrade over the prior CSS charts."* The pixel-test rule + the importmap chart-lib packaging gotcha were filed as deferred harvest issue **#144**. **Agent/doc-driven? ✅** — the visual gate caught a class of bug (a chart that renders blank while passing every assertion) that no other gate in the pipeline could, and the fix was encoded as a mechanical pixel-test plus a filed convention, not a one-off patch.
