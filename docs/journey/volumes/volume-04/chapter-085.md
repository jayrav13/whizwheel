## Chapter 85 — The agents Pages site ships and deploys live, lockstep-by-construction (2026-06-14)

Filed mid-conversation as **#129**, a GitHub Pages site *generated from* the agent definitions — so it cannot drift from them — was built in parallel by a subagent (the operator's *"The other two are sufficiently modular"* confirming it could run independent of the lifecycle work). The agent built `bin/build-agents-site` (standalone, pure-stdlib Ruby — no Rails/DB/Node, so it runs in the Pages workflow without `bundle install`): it parses each `.claude/agents/*.md` front-matter and body, derives a per-agent surface (purpose, model, tools, and a **writes-via-worktree-PR vs report-only** role inferred from whether the toolset has `Write`/`Edit` — `database-agent` correctly resolving to report-only), and emits a static roster index plus one page per agent. It hardened its own markdown renderer through testing — notably handling *"fenced code blocks **nested inside list items**"* (the historian's transcript step had a bash fence inside a numbered list that an early version mangled).

The lockstep property is structural, not a rule: the `.github/workflows/agents-pages.yml` workflow regenerates the site from `.claude/agents/*.md` on every push to `main` (path-filtered), with `_site/` gitignored — *"no checked-in artifact, so the site can't drift; no CI guard needed."* PR #132 merged at `dd31674`, the deploy workflow fired automatically, and the assistant confirmed it went live: **`http://jayravaliya.com/whizwheel/`** returning HTTP 200, *"deploy succeeded on the first try."*

The operator then asked the contract question: *"Have we codified that when agents update, the GH site needs to update too?"* The assistant gave the honest answer — not in CLAUDE.md text, but *"enforced more strongly than a written rule would be"* by the auto-regeneration mechanism — and recommended a small documentation note. The operator declined it: *"Ok, no need to codify, that's more perfect."* The assistant agreed and closed #129 with no follow-up: *"auto-generation *is* the enforcement, cleaner than a rule that could be forgotten."* **Agent/doc-driven? ✅** — and a notable case where the *right* answer was to **not** add a CLAUDE.md rule, because the mechanism already made the rule unforgettable; a structural enforcement chosen over a written one.
